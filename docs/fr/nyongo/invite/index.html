Vous êtes invité(e) sur Yonalar

Quelqu'un que vous connaissez utilise Yonalar pour suivre l'argent que vous vous prêtez, et vous a invité(e). Yonalar ne transfère pas d'argent : il garde seulement une trace commune que vous confirmez tous les deux.

Votre code d'invitation

Comment rejoindre

  1. Installez Yonalar sur votre téléphone.
  2. Créez votre compte.
  3. Ouvrez Profil → Code d'invitation et entrez le code ci-dessus.

Vos comptes sont alors reliés. Ce que cette personne a noté vous arrive sous forme de demandes : vous les acceptez, proposez une modification ou les refusez. Rien n'est ajouté à votre compte sans votre accord.
